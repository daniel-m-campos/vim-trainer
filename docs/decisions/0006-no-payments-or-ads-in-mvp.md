# 0006: No payments and no ads in the MVP

Date: 2026-10-11. Status: accepted.

The MVP has no accounts, no payments, no ads and no analytics. Progress lives in the
browser's localStorage with JSON export, import and reset. The result strip shows `p`
(replay) greyed out with a "pro" note and does nothing.

Why: see `docs/plan/07-monetization.md`. The free core stays free, there are no ads in
the practice loop, and pro is a one-time lifetime purchase decided after real users
exist. This record only pins that the MVP builds none of it.
