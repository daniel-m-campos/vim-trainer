# 0001: Plan the full scope before writing code

Date: 2026-10-11. Status: accepted.

The repo starts as planning documents only. Code begins when the plan docs in
`docs/plan/` have no open "To research" items that block the MVP.

Why: the research showed the market is full of half-finished trainers. The
differentiator is the measurement model and the content pipeline, both of which
are design problems, not coding problems.
